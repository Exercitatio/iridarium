## О проекте

**IRIDARIUM** — цифровая экосистема, объединяющая философию, квантовую физику, экономику и технологии в единую послойную структуру знаний. Проект развивает идеи цифрового рубля (RUBIN), криптографической безопасности эмитентов и цифровизации населения 40+.

Сайт представляет собой **одностраничное приложение** с раскрывающимися слоями контента и полнотекстовым поиском по всем документам проекта.

### Ключевые принципы

- **Послойность** — 6 тематических слоёв, от философии до экономики
- **Автономность** — работает офлайн как PWA, кэшируется через Service Worker
- **Минимум зависимостей** — чистый HTML / CSS / Vanilla JS
- **Русский язык** — интерфейс, документы и метаданные

## Возможности

- 🔍 **Полнотекстовый поиск** по всем документам с подсветкой совпадений
- 🌳 **Послойное раскрытие** — вложенные разделы без перезагрузки
- 📅 **Динамическое летоисчисление** — от С.М., от Потопа, от Петра + координаты в матрице 7×7
- 📱 **Адаптивная вёрстка** — десктоп, планшет, смартфон
- 🎨 **Иридесцентная эстетика** — переливающиеся градиенты, «стеклянные» карточки
- 📲 **PWA** — установка на домашний экран, офлайн-режим
- ⚡ **Без зависимостей** — никаких фреймворков, только браузер
